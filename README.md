# dono_tg_bot
A Telegram Bot for Nasli Dono Library(or for other online libraries)
**Features**
-----------------------------------------------------------------------------------------------
**Registration** - User adds phone numer, name and creates password(if possible gets profile from Telegram).
**Borrowing Book** - Bot checks if the book is available. If yes user adds returning date.
**Returning Book** - Admin or User marks it as returned.
***Reminder ordered books** - Fake function checks every hour.If the returning date has passed bot sends message to user.
**Ads** - User can write about ads to Admin.
